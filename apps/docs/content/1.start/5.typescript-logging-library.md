If you are choosing a TypeScript logging library, you are weighing what each option gives you out of the box against what you would have to build yourself. evlog is a TypeScript logging library that ships structured logs, wide events, and structured errors in one API, with zero transitive dependencies and ~6 kB gzip.

## What evlog gives you as a TypeScript logging library

- **Structured logs.** Every call emits a typed, machine-parseable event through the same pipeline, a drop-in replacement for `console.log`, pino, or consola.
- **Wide events.** You accumulate context over a request, job, or script and emit one event when it ends, success or failure. See [Wide Events](/learn/wide-events).
- **Structured errors.** Errors carry `why`, `fix`, and `link`, so your on-call and your AI agents get actionable context. See [Structured Errors](/learn/structured-errors).
- **Redaction and sampling built in.** PII is masked before any drain, and head + tail sampling keeps your bill tied to signal. See [Sampling](/learn/sampling).
- **Drains to the backends you already use.** Axiom, Datadog, Loki, ClickHouse, Sentry, and more. See [drain adapters](/integrate/adapters/overview).

The tradeoffs are documented too: four fixed levels (no custom levels), no plugin system, and level set at startup for the global `log.*` API. See [evlog vs pino, winston, consola](/reference/vs-other-loggers) for the full matrix and honest gaps.

## TypeScript across frameworks and runtimes

The same API works everywhere you run TypeScript:

- **Nuxt and Nitro**: auto-initialized via the Nuxt module, with `useLogger(event)` in handlers. See [Nuxt](/integrate/frameworks/nuxt) and [Nitro](/integrate/frameworks/nitro).
- **Cloudflare Workers**: first-class support with `waitUntil` integration. See [Cloudflare Workers](/integrate/frameworks/cloudflare-workers).
- **Bun, Deno, scripts, and CLIs**: no framework needed. See [Standalone TypeScript](/integrate/frameworks/standalone).

## Try it in under a minute

```bash
npm install evlog
```

```typescript [src/index.ts]
import { initLogger, createLogger } from 'evlog'

initLogger({ env: { service: 'my-app' } })

const log = createLogger({ jobId: 'sync-001' })
log.set({ batch: { size: 50, processed: 50 } })
log.emit()
```
