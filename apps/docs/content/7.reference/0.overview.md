## The three numbers worth knowing

Each one is measured on the same checkout request, and each page shows the run behind it.

- **~3µs per request** of CPU, against 1-50ms for a database query. [Performance](/reference/performance) names the paths where another logger is faster.
- **56% fewer bytes and 75% fewer events** than four log lines carrying the same request. [Log cost](/reference/cost) prices that against your own traffic.
- **~6.3 kB gzip and zero runtime dependencies**, so there is no tree to audit before you can log.
