Workers get the logger as an argument rather than from `useLogger()`, so `evlog/workers` needs no `nodejs_compat` flag:

```typescript [src/worker.ts]
import { toLoggerConfig, toMiddlewareOptions } from 'evlog'
import { initWorkersLogger, withEvlog } from 'evlog/workers'
import config from '../evlog.config'

initWorkersLogger(toLoggerConfig(config))

export default withEvlog(async (request, env, ctx, log) => {
  const user = await env.DB.prepare('SELECT * FROM users WHERE id = ?').bind(1).first()
  log.set({ user: { id: user.id, plan: user.plan } })

  return Response.json(user)
}, toMiddlewareOptions(config))
```

## What the wrapper does

`withEvlog` emits one event per request when the handler returns, and defers it until a streaming body completes. It registers each drain call with `ctx.waitUntil`, so a send to Axiom or PostHog finishes after the response has gone.

The event carries the method, the path, `cf-ray`, `traceparent` and the safe fields of `request.cf`. `requestId` is the `x-request-id` header when the caller sends one, `cf-ray` otherwise.

To own the emit yourself, use `defineWorkerFetch` and call `log.emit()` before returning.
