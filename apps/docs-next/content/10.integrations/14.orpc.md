---
title: oRPC
description: "Add the evlog middleware to your base procedure and wrap the handler with withEvlog(), then read context.log in every procedure."
---

::product-facts{entry="evlog/orpc" status="stable"}
::

Two pieces: a middleware that puts the logger on the procedure context, and a wrapper around the handler that opens and emits one event per request.

```typescript [server/orpc.ts]
import { os } from '@orpc/server'
import { RPCHandler } from '@orpc/server/fetch'
import { initLogger, toLoggerConfig, toMiddlewareOptions } from 'evlog'
import { evlog, withEvlog, type EvlogOrpcContext } from 'evlog/orpc'
import config from '../evlog.config'

initLogger(toLoggerConfig(config))

export const base = os.$context<EvlogOrpcContext>().use(evlog())

export const handler = withEvlog(new RPCHandler(router), toMiddlewareOptions(config))
```

## In a procedure

```typescript [server/procedures/users.ts]
export const getUser = base
  .input(z.object({ id: z.string() }))
  .handler(async ({ input, context }) => {
    const user = await db.findUser(input.id)
    context.log.set({ user: { id: input.id, plan: user.plan } })

    return user
  })
```

In a service the procedure calls, `useLogger()` from `evlog/orpc` returns the same logger.
