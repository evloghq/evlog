::

An AI endpoint is a black box in a request log: you see a 200 after four seconds, not the tokens it burned or the tool the model called. `evlog/ai` wraps the model and writes all of it onto the request's event.

::code-group
```typescript [Before]
export default defineEventHandler(async (event) => {
  const result = streamText({
    model: 'anthropic/claude-sonnet-4.6',
    messages,
  })
  return result.toTextStreamResponse()
})
```
```typescript [After]
import { useLogger } from 'evlog'
import { createAILogger } from 'evlog/ai'

export default defineEventHandler(async (event) => {
  const log = useLogger(event)
  const ai = createAILogger(log)

  const result = streamText({
    model: ai.wrap('anthropic/claude-sonnet-4.6'),
    messages,
  })
  return result.toTextStreamResponse()
})
```

## Cost

Pass prices per million tokens and the event carries the estimate:

```typescript [route:POST /api/chat]
const ai = createAILogger(log, {
  cost: { 'claude-sonnet-4.6': { input: 3, output: 15 } },
})
```

For tool execution timing and total generation time, add `createEvlogIntegration(ai)` to the AI SDK's `telemetry.integrations`. After `embed()` or `embedMany()`, `ai.captureEmbed({ usage, model, dimensions, count })` records the embedding call.
