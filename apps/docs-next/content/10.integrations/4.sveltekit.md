---
title: SvelteKit
description: "Export evlog's handle and handleError hooks once, read the logger from event.locals.log in endpoints and load functions, one event per request."
---

::product-facts{entry="evlog/sveltekit" status="stable"}
::

SvelteKit runs every request through `hooks.server.ts`. evlog provides both hooks, so the whole setup is that file and one type:

```typescript [src/hooks.server.ts]
import { initLogger, toLoggerConfig, toMiddlewareOptions } from 'evlog'
import { createEvlogHooks } from 'evlog/sveltekit'
import config from '../evlog.config'

initLogger(toLoggerConfig(config))

export const { handle, handleError } = createEvlogHooks(toMiddlewareOptions(config))
```

```typescript [src/app.d.ts]
import type { RequestLogger } from 'evlog'

declare global {
  namespace App {
    interface Locals {
      log: RequestLogger
    }
  }
}

export {}
```

If you already export a `handle`, compose them with `sequence()` from `@sveltejs/kit/hooks`.

## In an endpoint

```typescript [src/routes/api/users/[id]/+server.ts]
import { json } from '@sveltejs/kit'

export async function GET({ locals, params }) {
  const user = await db.findUser(params.id)
  locals.log.set({ user: { id: params.id, plan: user.plan } })

  return json(user)
}
```

Load functions receive the same `locals`. In a module under `$lib/server`, `useLogger()` from `evlog/sveltekit` returns the logger of the current request.
## Errors

Throw `createError()` with a `why` and a `fix`. The integration records it on the event and answers with the status you set:

```typescript [src/routes/api/checkout/+server.ts]
import { createError } from 'evlog'

throw createError({
  status: 402,
  message: 'Payment failed',
  why: 'Card declined by issuer',
  fix: 'Try a different payment method',
})
```
