---
title: Fastify
description: "Register the evlog plugin once, read the logger with request.log in routes and useLogger() underneath, one event per request."
---

::product-facts{entry="evlog/fastify" status="stable"}
::

evlog registers as a Fastify plugin and takes over `request.log`, so turn Fastify's own logger off:

```typescript [src/index.ts]
import Fastify from 'fastify'
import { initLogger, toLoggerConfig, toMiddlewareOptions } from 'evlog'
import { evlog } from 'evlog/fastify'
import config from '../evlog.config'

initLogger(toLoggerConfig(config))

const app = Fastify({ logger: false })
await app.register(evlog, toMiddlewareOptions(config))

await app.listen({ port: 3000 })
```

## In a route

```typescript [src/routes/users.ts]
app.get('/users/:id', async (request) => {
  const { id } = request.params as { id: string }

  const user = await db.findUser(id)
  request.log.set({ user: { id, plan: user.plan } })

  return user
})
```

In a service the route calls, `useLogger()` from `evlog/fastify` returns the same logger.
## Errors

A thrown error is recorded on the event. Answer with its fields from `setErrorHandler`:

```typescript [src/index.ts]
import { parseError } from 'evlog'

app.setErrorHandler((error, _request, reply) => {
  const { status, message, why, fix, link } = parseError(error)
  reply.status(status).send({ message, why, fix, link })
})
```
