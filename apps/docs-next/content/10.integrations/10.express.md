title: Express
description: "Register the evlog middleware once, read the logger with req.log in routes and useLogger() underneath, one event per request."

Express does not load `evlog.config.ts` on its own, so the entry file passes it in two calls: one to start the logger, one for the middleware.

```typescript [src/index.ts]
import express from 'express'
import { initLogger, toLoggerConfig, toMiddlewareOptions } from 'evlog'
import { evlog } from 'evlog/express'
import config from '../evlog.config'

initLogger(toLoggerConfig(config))

const app = express()
app.use(evlog(toMiddlewareOptions(config)))

app.listen(3000)
```

## In a route

```typescript [src/routes/users.ts]
app.get('/users/:id', async (req, res) => {
  const user = await db.findUser(req.params.id)
  req.log.set({ user: { id: req.params.id, plan: user.plan } })

  res.json(user)
})
```

In a service the route calls, `useLogger()` from `evlog/express` returns the same logger without passing `req` down.
## Errors

Express hands errors to a four-argument middleware. Record the error there and answer with its fields:

```typescript [src/index.ts]
import { createError, parseError } from 'evlog'

app.post('/checkout', () => {
  throw createError({ status: 402, message: 'Payment failed', why: 'Card declined by issuer', fix: 'Try a different payment method' })
})

app.use((err, req, res, next) => {
  req.log.error(err)
  const { status, message, why, fix, link } = parseError(err)
  res.status(status).json({ message, why, fix, link })
})
```
