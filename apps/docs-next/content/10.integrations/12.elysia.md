::

The plugin adds `log` to the context of every handler after it:

```typescript [src/index.ts]
import { Elysia } from 'elysia'
import { initLogger, toLoggerConfig, toMiddlewareOptions } from 'evlog'
import { evlog } from 'evlog/elysia'
import config from '../evlog.config'

initLogger(toLoggerConfig(config))

const app = new Elysia()
  .use(evlog(toMiddlewareOptions(config)))
  .listen(3000)
```

## In a handler

```typescript [src/index.ts]
app.get('/users/:id', async ({ log, params }) => {
  const user = await db.findUser(params.id)
  log.set({ user: { id: params.id, plan: user.plan } })

  return user
})
```

In a service the handler calls, `useLogger()` from `evlog/elysia` returns the same logger.
