---
title: Effect
description: "Provide evlog as layers and yield* EvlogLogger in any effect. The logger travels in the Effect context, not in AsyncLocalStorage."
---

::product-facts{entry="evlog/effect" status="stable"}
::

Two layers: one starts the logger, one wraps the router so each request gets its own event. The logger is an Effect service, `EvlogLogger`:

```typescript [src/index.ts]
import { createServer } from 'node:http'
import { NodeHttpServer, NodeRuntime } from '@effect/platform-node'
import { Layer } from 'effect'
import { HttpRouter } from 'effect/http'
import { toLoggerConfig, toMiddlewareOptions } from 'evlog'
import { initLoggerLayer, routerLayer } from 'evlog/effect'
import config from '../evlog.config'

const Server = HttpRouter.serve(
  Routes.pipe(Layer.provide(routerLayer(toMiddlewareOptions(config)))),
  { disableLogger: true },
).pipe(
  Layer.provide(NodeHttpServer.layer(createServer, { port: 3000 })),
  Layer.provide(initLoggerLayer(toLoggerConfig(config))),
)

NodeRuntime.runMain(Layer.launch(Server))
```

## In a route

```typescript [src/routes/users.ts]
import { Effect } from 'effect'
import { HttpRouter, HttpServerResponse } from 'effect/http'
import { EvlogLogger } from 'evlog/effect'

export const UserRoute = HttpRouter.add('GET', '/users/:id', Effect.gen(function* () {
  const log = yield* EvlogLogger
  const { id } = yield* HttpRouter.params

  const user = yield* Users.find(id)
  log.set({ user: { id, plan: user.plan } })

  return HttpServerResponse.jsonUnsafe(user)
}))
```

Any effect the route runs can `yield* EvlogLogger` and add to the same event. Background work runs in a nested `withLogger` and produces its own event, where other integrations use `log.fork()`.
