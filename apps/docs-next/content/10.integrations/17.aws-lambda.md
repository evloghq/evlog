title: AWS Lambda
description: "Start evlog once per cold start and create one logger per invocation or per queue record, emitted in a finally block."
---

::

A Lambda function has no request middleware, so the handler creates and emits its loggers. Start evlog outside the handler, where it runs once per cold start:

```typescript [src/handler.ts]
import type { SQSEvent } from 'aws-lambda'
import { createLogger, initLogger, toLoggerConfig } from 'evlog'
import config from '../evlog.config'

initLogger(toLoggerConfig(config))

export async function handler(event: SQSEvent) {
  for (const record of event.Records) {
    const log = createLogger({ messageId: record.messageId })

    try {
      log.set({ queue: { name: record.eventSourceARN } })
      await process(JSON.parse(record.body))
    }
    catch (error) {
      log.error(error instanceof Error ? error : new Error(String(error)))
      throw error
    }
    finally {
      log.emit()
    }
  }
}
```

## One logger per unit of work

Create the logger inside the loop, not at the top of the file. A logger shared by every record would merge their fields into one event, and a warm container would carry them into the next invocation.

For an API Gateway handler, `createRequestLogger({ method, path })` adds the HTTP fields, and one logger covers the invocation.

Set `silent` in the config when a drain is the only destination, so CloudWatch does not receive a second copy on stdout.
