The drain inserts each batch of wide events into a [ClickHouse](https://clickhouse.com) table over HTTP. It uses asynchronous inserts by default, so ClickHouse groups the small writes itself instead of creating one part per request.

```typescript [evlog.config.ts]
import { defineEvlog } from 'evlog'
import { createClickHouseDrain } from 'evlog/clickhouse'

export default defineEvlog({
  service: 'my-app',
  drain: createClickHouseDrain(),
})
```

## Credentials

```bash [.env]
CLICKHOUSE_ENDPOINT=https://abc123.eu-west-1.aws.clickhouse.cloud:8443
CLICKHOUSE_USER=default
CLICKHOUSE_PASSWORD=your-password
```

The database is `default` and the table `evlog_events` unless you set `CLICKHOUSE_DATABASE` or `CLICKHOUSE_TABLE`. A local instance without a password needs only the endpoint.

## The table

The drain does not create the table. This schema matches the rows it writes, with the common fields as columns and the whole event in `data`:

```sql [schema.sql]
CREATE TABLE IF NOT EXISTS evlog_events
(
  timestamp     DateTime64(3, 'UTC'),
  level         LowCardinality(String),
  service       LowCardinality(String),
  environment   LowCardinality(String),
  request_id    String,
  trace_id      String,
  span_id       String,
  method        LowCardinality(String),
  path          String,
  status        Nullable(UInt16),
  duration      String,
  duration_ms   Nullable(UInt32),
  error_name    String,
  error_message String,
  data          String
)
ENGINE = MergeTree
PARTITION BY toYYYYMM(timestamp)
ORDER BY (service, environment, timestamp)
TTL toDateTime(timestamp) + INTERVAL 30 DAY;
```

Any field not in a column is still in `data`, and `JSONExtract` reads it:

```sql
SELECT path, quantile(0.95)(duration_ms) AS p95_ms
FROM evlog_events
WHERE timestamp > now() - INTERVAL 1 DAY
  AND JSONExtractString(data, 'user', 'plan') = 'pro'
GROUP BY path
ORDER BY p95_ms DESC
LIMIT 20;
```

For another schema, pass `transform`: it receives a wide event and returns the row.

## Options

| Option | Env | What it is |
| --- | --- | --- |
| `endpoint` | `CLICKHOUSE_ENDPOINT` | The HTTP interface URL |
| `database` | `CLICKHOUSE_DATABASE` | `default` by default |
| `table` | `CLICKHOUSE_TABLE` | `evlog_events` by default |
| `username` | `CLICKHOUSE_USER` | `default` by default |
| `password` | `CLICKHOUSE_PASSWORD` | Omit for a local instance without auth |
| `asyncInsert` | | `true` by default |
| `waitForAsyncInsert` | | Wait for the insert to be flushed, `false` by default |
| `transform` | | Maps an event to a row, `toClickHouseRow` by default |
| `timeout` | | Request timeout in ms, `5000` by default |
| `retries` | | Retries on a transient failure, `2` by default |

On Nuxt, each variable also reads with a `NUXT_` prefix, such as `NUXT_CLICKHOUSE_ENDPOINT`.
