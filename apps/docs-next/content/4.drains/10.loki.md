title: Grafana Loki
description: "Send wide events to Loki, self-hosted or on Grafana Cloud, with a few low-cardinality fields as stream labels and the rest as JSON."
---

::product-facts{entry="evlog/loki" status="stable"}
::

[Loki](https://grafana.com/oss/loki/) indexes labels, not content. The drain turns a few fields of each wide event into stream labels and sends the whole event as the log line, which LogQL's `| json` reads back.

```typescript [evlog.config.ts]
import { defineEvlog } from 'evlog'
import { createLokiDrain } from 'evlog/loki'

export default defineEvlog({
  service: 'my-app',
  drain: createLokiDrain(),
})
```

## Credentials

Self-hosted, the endpoint is enough:

```bash [.env]
LOKI_ENDPOINT=http://localhost:3100
```

On Grafana Cloud, add the instance ID and a token. Together they are sent as Basic auth:

```bash [.env]
LOKI_ENDPOINT=https://logs-prod-eu-west-0.grafana.net
LOKI_USER=123456
LOKI_API_KEY=glc_your_token
```

A token without a user is sent as a Bearer token. A multi-tenant self-hosted Loki takes `LOKI_TENANT_ID`, sent as `X-Scope-OrgID`.

## Labels

Each distinct set of label values is a separate stream in Loki, so labels must stay few and low-cardinality. The drain labels by `service`, `environment` and `level`:

```logql
{service="my-app", level="error"} | json | status >= 500
```

`labelFields` changes the list, and `labels` adds static ones such as a region. Never label by `requestId`, `userId` or `path`: each value would open a new stream.

## Options

| Option | Env | What it is |
| --- | --- | --- |
| `endpoint` | `LOKI_ENDPOINT` | The Loki base URL, without the push path |
| `apiKey` | `LOKI_API_KEY` | A token |
| `user` | `LOKI_USER` | The Grafana Cloud instance ID. Switches to Basic auth |
| `tenantId` | `LOKI_TENANT_ID` | The tenant, for multi-tenant Loki |
| `labelFields` | | Fields promoted to labels, `['service', 'environment', 'level']` by default |
| `labels` | | Static labels on every stream |
| `timeout` | | Request timeout in ms, `5000` by default |
| `retries` | | Retries on a transient failure, `2` by default |

`GRAFANA_API_KEY` and `GRAFANA_USER` are read too. On Nuxt, each variable also reads with a `NUXT_` prefix, such as `NUXT_LOKI_ENDPOINT`.
