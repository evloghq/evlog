::

The drain sends each wide event to [Better Stack](https://betterstack.com/telemetry) as one log line with the event's fields attached.

```typescript [evlog.config.ts]
import { defineEvlog } from 'evlog'
import { createBetterStackDrain } from 'evlog/better-stack'

export default defineEvlog({
  service: 'my-app',
  drain: createBetterStackDrain(),
})
```

## Credentials

Create an HTTP source in Better Stack and copy its source token and ingesting host:

```bash [.env]
BETTER_STACK_API_KEY=your-source-token
BETTER_STACK_ENDPOINT=https://s1234567.eu-nbg-2.betterstackdata.com
```

Without `BETTER_STACK_ENDPOINT`, the drain posts to `https://in.logs.betterstack.com`.

## Options

| Option | Env | What it is |
| --- | --- | --- |
| `apiKey` | `BETTER_STACK_API_KEY` | The source token |
| `endpoint` | `BETTER_STACK_ENDPOINT` | The ingesting host, `https://in.logs.betterstack.com` by default |
| `timeout` | | Request timeout in ms, `5000` by default |
| `retries` | | Retries on a transient failure, `2` by default |

On Nuxt, each variable also reads with a `NUXT_` prefix, such as `NUXT_BETTER_STACK_API_KEY`.

::callout{icon="i-lucide-arrow-up-circle" color="neutral"}
evlog 3 renamed the `sourceToken` option to `apiKey`, and `BETTER_STACK_SOURCE_TOKEN` to `BETTER_STACK_API_KEY`. `evlog upgrade` rewrites both. See [Upgrade to v3](/start/upgrade).
::
