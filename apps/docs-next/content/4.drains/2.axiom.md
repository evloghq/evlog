[Axiom](https://axiom.co) indexes every field of an event, so `user.plan` or `cart.total` is queryable the moment the first event arrives, with no schema to declare.

```typescript [evlog.config.ts]
import { defineEvlog } from 'evlog'
import { createAxiomDrain } from 'evlog/axiom'

export default defineEvlog({
  service: 'my-app',
  drain: createAxiomDrain(),
})
```

## Credentials

Create a dataset and an API token with ingest permission, then set:

```bash [.env]
AXIOM_API_KEY=xaat-your-token
AXIOM_DATASET=your-dataset
```

Axiom calls this credential an API token (`xaat-...`). evlog names the option `apiKey`, like every other drain. Without both values, the drain logs which variable is missing and sends nothing.

## Options

Pass options to override the environment:

| Option | Env | What it is |
| --- | --- | --- |
| `apiKey` | `AXIOM_API_KEY` | The ingest token |
| `dataset` | `AXIOM_DATASET` | Where events land |
| `orgId` | `AXIOM_ORG_ID` | Required for personal access tokens |
| `edgeUrl` | `AXIOM_EDGE_URL` | An edge ingest endpoint. Cannot be set with `baseUrl` |
| `baseUrl` | `AXIOM_URL` | The API base URL. Cannot be set with `edgeUrl` |
| `timeout` | | Request timeout in ms, `5000` by default |
| `retries` | | Retries on a transient failure, `2` by default |

On Nuxt, each variable also reads with a `NUXT_` prefix, such as `NUXT_AXIOM_API_KEY`.

::callout{icon="i-lucide-arrow-up-circle" color="neutral"}
evlog 3 removed the `token` option and the `AXIOM_TOKEN` variable. See [Upgrade to v3](/start/upgrade#credential-aliases-removed).
::
