evlog names each product with one plain noun, and uses the same word in the URL, the docs and the code. When a page says drain, the function is `createAxiomDrain`, the hook is `evlog:drain`, and the URL is `/drains`.

## Products

| Product | What it names | In the code |
| --- | --- | --- |
| [Events](/events) | The wide event, and what shapes it: sampling, redaction, enrichers | `log.set()`, `createLogger()`, `useLogger()` |
| [Errors](/errors) | Structured errors and their catalogs | `createError()`, `defineErrorCatalog()`, `parseError()` |
| [Drains](/drains) | Where events leave the process | `createAxiomDrain()`, `evlog:drain`, `evlog/pipeline` |
| [Map](/map) | The static score of your entry points, and the CI gate on it | `evlog map`, `evlog.map.json` |
| [Signals](/signals) | A model's answer to one question about an event | `@evlog/signals`, `defineSignal()` |
| [Audit](/audit) | Who did what, on which resource, signed | `log.audit()`, `auditOnly()`, `signed()` |
| [Skills](/skills) | The agent skills evlog publishes | `skills/`, `evlog agents` |
| [Telemetry](/telemetry) | One event per run, for tools that run on other people's machines | `@evlog/telemetry` |

## Why one word each

- **Drains, not adapters.** The code has always said drain. A nav that says adapter sends the reader looking for a word the API does not use.
- **Map, not score.** `evlog map` is the command and `evlog.map.json` the file. The number it prints is the observability score, a reading of the map rather than a second product.
- **Skills, not agents.** The product is the set of skills in `skills/`. `evlog agents` is the command that installs them.
- **Signals and Telemetry are products.** Both are packages with their own version line. They were pages under use cases, which hid them from anyone scanning the nav.

## Terms

| evlog says | Not | Why |
| --- | --- | --- |
| **wide event** | wide log, fat event | One event per unit of work, with every field the work touched. Structured log is the category, not this |
| **drain** | sink, exporter, transport | Where events leave the process. Exporter is OpenTelemetry's word, transport is pino's |
| **enricher** | middleware, context provider | It adds fields to an event before it is emitted. It is not in the request chain |
| **pipeline** | chain, middleware stack | `createDrainPipeline()`: batching, retry and buffering around a drain |
| **error catalog** | error registry, error map | `defineErrorCatalog()` is the API, and the word you can grep for |
| **`log.fork()`** | child logger | It branches the accumulated context for background work and can be discarded. pino's `child()` only inherits bindings |
