The `evlog` executable comes with the `evlog` package. It runs [`@evlog/cli`](https://npmjs.com/package/@evlog/cli) when it is installed and fetches it otherwise, so `npx evlog init` works in a project that has nothing yet. It needs Node.js 22 or later.

```bash [Terminal]
npx evlog <command>
```

| Command | What it does |
| --- | --- |
| `evlog init` | Installs evlog, registers the framework integration, and writes `evlog.config.ts`. See [Installation](/start/installation) |
| `evlog map` | Scores the entry points and names the three to fix first. See [Map](/map) |
| `evlog logs` | Reads the events the file system drain wrote: the latest, the failures, the slowest, or one request in full |
| `evlog agents` | Installs the agent skills and writes the evlog conventions into `AGENTS.md`. See [Skills](/skills) |
| `evlog doctor` | Checks that evlog is installed, resolvable, and writing logs where you expect |
| `evlog config` | Shows the `evlog.config.ts` that applies here, and where each setting comes from |
| `evlog telemetry` | Shows, enables or disables the CLI's own anonymous usage telemetry |

`evlog upgrade`, which applies the [v3 changes](/start/upgrade) to your code, is planned for `@evlog/cli` 1.0 and not released yet.

`@evlog/cli` has its own version line, `1.0.0-beta` next to evlog 3. Its peer range accepts evlog 2.31 or later and the evlog 3 betas.
