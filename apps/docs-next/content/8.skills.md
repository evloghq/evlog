An agent asked to add logging writes `console.log`. With the evlog skills installed, it writes a wide event, a structured error, and an audit call where the route touches money or auth, because the skills carry the same rules as these pages.

```bash [Terminal]
pnpm dlx skills add https://www.evlog.dev
```

Claude Code, Cursor, Codex and any agent that reads [Agent Skills](https://agentskills.io) pick them up.

## The skills

| Skill | Use it to |
| --- | --- |
| `review-logging-patterns` | Find scattered logs, missing context and bare `Error`s, and move a codebase to evlog. Runs [`evlog map`](/map) first when the framework is supported |
| `build-audit-logs` | Design, wire and review an [audit](/audit) trail: policy, `auditEnricher`, `auditOnly`, `signed`, denials, redaction, tests |
| `analyze-logs` | Read the NDJSON the [file system drain](/drains) writes to `.evlog/logs/`: errors, slow requests, one request end to end |

## Conventions in AGENTS.md

`evlog agents` installs the skills and writes a short block of evlog conventions into your project's `AGENTS.md`: the rules an agent follows on every logging change, which the skills then back with the detail.

```bash [Terminal]
pnpm dlx evlog agents
```

It installs globally by default, into `~/.agents/skills`, and links that copy into `~/.claude/skills` for Claude Code. `--local` installs into the project instead.
