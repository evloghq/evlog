The fastest path is one command. `evlog init` detects your framework, asks what it cannot infer, and shows its plan before it installs the package, writes `evlog.config.ts` and adds the integration:

```bash [Terminal]
pnpm dlx evlog init
```

The steps below are what it does, if you prefer to do them by hand.

::callout{icon="i-lucide-arrow-up-circle" color="neutral"}
Upgrading from evlog 2? Read [Upgrade to v3](/start/upgrade) before you change the version.
::

## 1. Install the package

```bash [Terminal]
pnpm add evlog
```

evlog 3 requires Node.js 22 or later.

## 2. Create the config

Every option lives in one file at the root of your app:

```typescript [evlog.config.ts]
import { defineEvlog } from 'evlog'

export default defineEvlog({
  service: 'my-app',
})
```

evlog looks for `evlog.config.ts` (or `.mts`, `.js`, `.mjs`) in your app and walks up to the workspace root, so one file at the root of a monorepo covers every app without its own. [Configuration](/reference/configuration) lists every option.

## 3. Wire your framework

Nuxt, Nitro and TanStack Start load the config file on their own. Other frameworks import it in one line and pass it to their integration:

::framework-tabs
```typescript [Nuxt] nuxt.config.ts
export default defineNuxtConfig({
  modules: ['evlog/nuxt'],
})
```
```typescript [Next.js] lib/evlog.ts
import { createEvlog } from 'evlog/next'
import config from '../evlog.config'

export const { withEvlog, useLogger, log, createError } = createEvlog(config)
```
```typescript [Hono] src/index.ts
import { Hono } from 'hono'
import { initLogger, toLoggerConfig, toMiddlewareOptions } from 'evlog'
import { evlog, type EvlogVariables } from 'evlog/hono'
import config from '../evlog.config'

initLogger(toLoggerConfig(config))

const app = new Hono<EvlogVariables>()
app.use(evlog(toMiddlewareOptions(config)))
```
```typescript [Nitro] nitro.config.ts
import { defineConfig } from 'nitro'
import evlog from 'evlog/nitro'

export default defineConfig({
  modules: [evlog()],
})
```
```typescript [SvelteKit] src/hooks.server.ts
import { initLogger, toLoggerConfig, toMiddlewareOptions } from 'evlog'
import { createEvlogHooks } from 'evlog/sveltekit'
import config from '../evlog.config'

initLogger(toLoggerConfig(config))

export const { handle, handleError } = createEvlogHooks(toMiddlewareOptions(config))
```
```typescript [TanStack Start] nitro.config.ts
import { defineConfig } from 'nitro'
import evlog from 'evlog/nitro'

export default defineConfig({
  experimental: { asyncContext: true },
  modules: [evlog()],
})
```
```tsx [React Router] app/root.tsx
import { initLogger, toLoggerConfig, toMiddlewareOptions } from 'evlog'
import { evlog } from 'evlog/react-router'
import config from '../evlog.config'

initLogger(toLoggerConfig(config))

export const middleware: Route.MiddlewareFunction[] = [
  evlog(toMiddlewareOptions(config)),
]
```
```typescript [Astro] src/middleware.ts
import { defineMiddleware } from 'astro:middleware'
import { createRequestLogger, initLogger, toLoggerConfig } from 'evlog'
import config from '../evlog.config'

initLogger(toLoggerConfig(config))

export const onRequest = defineMiddleware(async ({ request, locals }, next) => {
  const log = createRequestLogger({ method: request.method, path: new URL(request.url).pathname })
  locals.log = log
  try {
    return await next()
  }
  finally {
    log.emit()
  }
})
```
```typescript [Express] src/index.ts
import express from 'express'
import { initLogger, toLoggerConfig, toMiddlewareOptions } from 'evlog'
import { evlog } from 'evlog/express'
import config from '../evlog.config'

initLogger(toLoggerConfig(config))

const app = express()
app.use(evlog(toMiddlewareOptions(config)))
```
```typescript [Fastify] src/index.ts
import Fastify from 'fastify'
import { initLogger, toLoggerConfig, toMiddlewareOptions } from 'evlog'
import { evlog } from 'evlog/fastify'
import config from '../evlog.config'

initLogger(toLoggerConfig(config))

const app = Fastify({ logger: false })
await app.register(evlog, toMiddlewareOptions(config))
```
```typescript [Elysia] src/index.ts
import { Elysia } from 'elysia'
import { initLogger, toLoggerConfig, toMiddlewareOptions } from 'evlog'
import { evlog } from 'evlog/elysia'
import config from '../evlog.config'

initLogger(toLoggerConfig(config))

const app = new Elysia().use(evlog(toMiddlewareOptions(config)))
```
```typescript [NestJS] src/app.module.ts
import { Module } from '@nestjs/common'
import { toMiddlewareOptions } from 'evlog'
import { EvlogModule } from 'evlog/nestjs'
import config from '../evlog.config'

@Module({
  imports: [EvlogModule.forRoot(toMiddlewareOptions(config))],
})
export class AppModule {}
```
```typescript [oRPC] server/orpc.ts
import { os } from '@orpc/server'
import { RPCHandler } from '@orpc/server/fetch'
import { initLogger, toLoggerConfig, toMiddlewareOptions } from 'evlog'
import { evlog, withEvlog, type EvlogOrpcContext } from 'evlog/orpc'
import config from '../evlog.config'

initLogger(toLoggerConfig(config))

export const base = os.$context<EvlogOrpcContext>().use(evlog())
export const handler = withEvlog(new RPCHandler(router), toMiddlewareOptions(config))
```
```typescript [Effect] src/index.ts
import { toLoggerConfig, toMiddlewareOptions } from 'evlog'
import { initLoggerLayer, routerLayer } from 'evlog/effect'
import config from '../evlog.config'

const Server = HttpRouter.serve(
  Routes.pipe(Layer.provide(routerLayer(toMiddlewareOptions(config)))),
  { disableLogger: true },
).pipe(
  Layer.provide(NodeHttpServer.layer(createServer, { port: 3000 })),
  Layer.provide(initLoggerLayer(toLoggerConfig(config))),
)
```
```typescript [Cloudflare Workers] src/worker.ts
import { toLoggerConfig, toMiddlewareOptions } from 'evlog'
import { initWorkersLogger, withEvlog } from 'evlog/workers'
import config from '../evlog.config'

initWorkersLogger(toLoggerConfig(config))

export default withEvlog(async (request, env, ctx, log) => {
  return Response.json({ ok: true })
}, toMiddlewareOptions(config))
```
```typescript [AWS Lambda] src/handler.ts
import { initLogger, toLoggerConfig } from 'evlog'
import config from '../evlog.config'

// Once per cold start; create a logger per invocation in the handler.
initLogger(toLoggerConfig(config))
```
```typescript [Standalone] scripts/sync.ts
import { initLogger, toLoggerConfig } from 'evlog'
import config from '../evlog.config'

initLogger(toLoggerConfig(config))
```
::

Some frameworks need one more file, such as the `Locals` type on SvelteKit or the middleware flag on React Router. Your framework's page under [Integrations](/integrations) has the full setup.

```bash [Terminal]
pnpm dlx skills add https://www.evlog.dev
```
