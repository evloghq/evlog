# Security

## Supported versions

| Version | Supported |
| --- | --- |
| 3.x (beta) | Fixes ship in the next beta |
| 2.x | Yes. Features and fixes until evlog 3.0 ships on January 18, 2027, then security and critical bug fixes until July 18, 2027 |
| < 2.0 | No |

## Reporting a vulnerability

**Please do not** open a public issue or discussion for security-sensitive bugs.

Use **[GitHub Security Advisories (private report)](https://github.com/evloghq/evlog/security/advisories/new)** so maintainers can assess and release a fix responsibly.

Include:

- A clear description and impact
- Affected evlog version(s) and, if relevant, the framework integration (Nuxt, Nitro, etc.)
- Steps to reproduce or a minimal code sample, when safe to share

We will triage reports as soon as we can. Thank you for helping keep users safe.
